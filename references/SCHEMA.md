# Data Bite 인포그래픽 내용 명세 (spec.json)

한 장짜리 인포그래픽의 **내용만** 정한다. 글자 크기 · 색 · 배치는 견본(`assets/style.css`)으로 고정돼 있고, 생성기는 캔버스 길이만 내용에 맞춰 늘리거나 줄인다.

## 원칙
1. **항목의 핵심 = 원본 장표의 타이틀 내용.** 요약 장(Summary)에 나열된 항목 제목과 그 항목 장표의 타이틀이 말하는 것을 그대로 살린다. 뜻을 바꾸거나 다른 수치로 주제를 옮기지 않는다.
2. **크게 쓰는 자리(hero)는 둘 중 하나.**
   - `num`: 타이틀 내용을 직접 지지하는 근거 숫자가 원본에 있을 때만. 타이틀이 "긍정 74%로 우세"면 74%. 표본 수(조사 인원 10명) · 날짜 · 가격처럼 타이틀 주장을 지지하지 않는 숫자는 쓰지 않는다.
   - `keyword`: 근거 숫자가 없거나 약하면 핵심 키워드(한국어 2~10자, 한 줄). 예: "충전으로 이동", "표준 보기 부재".
3. **숫자는 원본 그대로.** 반올림 · 환산 · 추정 금지. 원본에 없는 수치를 만들지 않는다.
4. **핵심만.** 출처 · 수집 기준 · 맥락 문장 · 장단점 · 부가 수치는 넣지 않는다.
5. **문구는 사람 말처럼(humanizer).** 짧고 구체적인 한국어. 과장 · 홍보 어휘 · "~를 보여줌/시사함" 해설 금지. 긴 대시(— –) 금지. hero 숫자를 제목에서 다시 쓰지 않는다. 제목은 한 줄 24자 이내, `\n` 으로 2줄까지.
6. **차트는 타이틀을 뒷받침할 때만.** 원본 숫자로만, 행 최대 6개. 없어도 된다(`none`).
7. **항목 순서 = 요약 장 순서.** 한 항목이 원본 2장에 걸치면 하나로 합친다.

## JSON 형식
```json
{
  "week": "01",
  "period": "2026 · 1/5 ~ 1/9",
  "items": [
    {
      "id": "01",
      "source_title": "원본 요약 장의 항목 제목을 글자 그대로",
      "kicker": "워치 수면 · VOC",
      "hero": { "kind": "num", "value": "48", "unit": "%", "unit_pre": false },
      "title": "수면 점수가 들쭉날쭉하다는\n불만이 가장 많다",
      "chart": { "type": "bars", "rows": [["점수 편차", 48], ["기록 누락", 22]], "unit": "%", "highlight": 0 },
      "chips": [],
      "illust": { "kind": "device", "subject": "a smartwatch on a bedside table showing an uneven sleep chart" }
    }
  ],
  "notes": "판단이 애매했던 점을 짧게"
}
```
- `hero` 키워드형: `{ "kind": "keyword", "text": "충전으로 이동" }`
- `hero.value` 에 부호 포함 가능("+13.1", unit "%p"). `unit_pre: true` 면 단위를 숫자 앞에("$").
- `kicker`: 주제 · 출처 종류를 짧게(22자 이내, 예: "폴더블 · VOC").
- `chips`: 최대 3개, 각 8자 이내. 필요 없으면 [].
- `illust.kind`: device · app · icon · symbol. `subject` 는 영어 한 문장, 그릴 대상만(스타일 말 · 로고 · 상표 · 글자 금지).

## 차트 종류
- `line`: 시간 추이. `x` · `y` · `unit` · `labels`(최대 2개, `i` = 인덱스, `text`).
- `bars`: 순위 · 비교. `rows`: [["이름", 값], ...] 최대 6행 · `unit` · `highlight`(행 인덱스) · `max`(선택).
- `waffle`: 100명 중 몇 명. `parts`: [["매일", 2.1], ...] (합 ≤ 100).
- `dumbbell`: 그룹별 전후. `groups`: [["이름", [전, 후], [전, 후]], ...] · `metrics`(1~2개) · `before` · `after` · `unit`.
- `stack`: 100% 구성 한 줄. `parts`: [["이름", 값], ...] 최대 5개.
- `multi`: 차트 2개를 한 항목에(숫자 묶음이 둘일 때만). `charts`: [{"title": "...", "type": "bars", ...}, ...]
- `none`: 차트 없음.

## 그림 파일
`illust/W<week>/<id>.png` (render.py `--illust` 로 폴더 지정). 없으면 그 항목은 그림 없이 그린다.

전체 예시: `examples/sample.spec.json` (가상 데이터).
